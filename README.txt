# 博茨瓦纳中文旅游网站框架 V1

本版本依据你们提供的中文模块指令与图片素材搭建，顶部仅保留：首页、体验、探索、住宿、旅游信息。

## 结构
- 首页：参考原官网的“大屏主视觉 + 探索/体验/住宿 + 旅行信息 + 游客评价”节奏。
- 体验：17项体验轮播 + 17个可点击详情。
- 探索：16个目的地卡片 + 16个可点击详情 + 搜索。
- 住宿：Shinde、Okuti、Kanana及详情页 + 搜索。
- 旅游信息：6个信息入口 + 详情页 + 搜索。
- 全部详情页复用统一页脚。
- 所有页面支持手机、平板、电脑。
- 使用 hash 路由，适合直接部署 GitHub Pages，不需要额外服务器。

## 上传
把 index.html、app.js、styles.css、data.js、assets 文件夹一起上传到 GitHub 仓库根目录。
然后 Settings → Pages → Deploy from a branch → main → /(root)。

## 后续
图片和文案如果继续调整，只需替换 assets 或 data.js，不需要重做页面结构。
